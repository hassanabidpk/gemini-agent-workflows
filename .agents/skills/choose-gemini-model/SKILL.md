# Choose a Gemini model

1. Read [the model guide](references/models.md). Identify the output, how many steps must stay coordinated, and what will show the task is done.
2. Choose a starting model and name the condition that would make you switch. Use the picker or the account's model list if available. Treat access and quota as surface-specific.
3. Give the user one concrete way to verify the result. For document work, cite the page or section. For code, name the test or other observable result. For images, name the details the user should inspect.

Return the recommendation and the reason. Leave model changes and execution to the normal user-controlled flow.
